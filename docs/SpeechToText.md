# SpeechToText - 语音转文字 (ASR)

基于本地离线 Whisper 语音识别模型，将 WAV/MP3 语音转写为精准文本。

## 核心特性

- **100% 本地离线推理**：高性能本地神经网络推理，零外部进程或云端网络依赖。
- **自动调用全局激活模型**：无需在动作中手动配置 `model_path`，运行时自动调取用户在设置界面中选择激活的 Whisper 模型 (`Whisper-Base` / `Whisper-Tiny` / `Whisper-Small`)。
- **硬件自动加速**：检测到独立显卡时自动启用硬件加速，无独立显卡时自动启用 CPU 多核优化加速。

## 输入参数

| 参数名 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `audio_file` | `string` | `""` | 待识别的音频文件路径 (.wav, .mp3, .m4a) |
| `language` | `string` | `zh` | 识别语言：`zh` (中文), `en` (英文), `auto` (自动) |

## 输出

- 返回从音频中转译识别出带汉字与标点的精准字符串文本。
