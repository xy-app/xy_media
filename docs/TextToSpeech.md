# 文本转语音 (TextToSpeech) (TextToSpeech)

使用系统自带语音将输入的文字大声朗读播报出来

## 运行参数

* **朗读文本内容 (`text`)**
  * 类型: `string`
  * 默认值: `"操作已完成"`
  * 描述: 需要语音播报的纯文本内容。常用预设：`操作已完成`, `警告：检测到异常情况`, `任务执行完毕`。
* **朗读语速 (-10 到 10) (`rate`)**
  * 类型: `number`
  * 默认值: `0`
  * 描述: 发音语速快慢调节 (-10 到 10，0为正常)。常用预设：`-2`, `0`, `2`, `5`。
* **语音音量 (0 - 100) (`volume`)**
  * 类型: `number`
  * 默认值: `100`
  * 描述: 发音音量大小 (0 到 100)。常用预设：`50`, `80`, `100`。
* **等待朗读完成 (`wait`)**
  * 类型: `number`
  * 默认值: `1`
  * 描述: 是否阻塞直到朗读声音结束 (1为阻塞等待，0为后台异步朗读)。常用预设：`1`, `0`。

## 输出

* 类型: `string`
* 描述: 语音播报执行结果回执。

## 使用示例

```json
{
    "tag":  "TextToSpeech",
    "text":  "操作已完成",
    "rate":  0,
    "volume":  100,
    "wait":  1
}
```
