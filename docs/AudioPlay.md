# 播放音频 (AudioPlay) (AudioPlay)

播放本地音频文件 (如 MP3、WAV 等)，支持调节音量和循环播放

## 运行参数

* **音频文件路径 (`file_path`)**
  * 类型: `string`
  * 默认值: `""`
  * 描述: 本地音频文件的绝对路径或相对路径。常用预设：`C:/audio/notification.wav`, `C:/music/bgm.mp3`。
* **音量 (0 - 100) (`volume`)**
  * 类型: `number`
  * 默认值: `80`
  * 描述: 音频播放音量大小 (0-100)。常用预设：`50`, `80`, `100`。
* **循环播放 (`repeat`)**
  * 类型: `number`
  * 默认值: `0`
  * 描述: 是否开启循环重复播放 (1 为开启，0 为单次)。常用预设：`0`, `1`。
* **等待播放完成 (`wait`)**
  * 类型: `number`
  * 默认值: `0`
  * 描述: 是否同步阻塞直到音频播放结束 (1 为阻塞，0 为后台播放)。常用预设：`0`, `1`。

## 输出

* 类型: `string`
* 描述: 音频播放启动状态或完成标识。

## 使用示例

```json
{
    "tag":  "AudioPlay",
    "file_path":  "",
    "volume":  80,
    "repeat":  0,
    "wait":  0
}
```
