# 打开相机设备 (CameraOpen) (CameraOpen)

打开本地 USB 工业相机、摄像头或网络视频流

## 运行参数

* **相机设备/视频源 (`device`)**
  * 类型: `string`
  * 默认值: `"0"`
  * 描述: 摄像头设备索引编号 (0, 1, 2) 或 RTSP/HTTP 串流地址。常用预设：`0`, `1`, `2`, `rtsp://192.168.1.100:554/live`。
* **期望分辨率 (W, H) (`size`)**
  * 类型: `string`
  * 默认值: `""`
  * 描述: 相机采集期望的分辨率尺寸，留空保持硬件默认。常用预设：``, `1280, 720`, `1920, 1080`, `640, 480`。
* **相机句柄输出变量 (`output_var`)**
  * 类型: `string`
  * 默认值: `"camera"`
  * 描述: 保存打开后的相机句柄变量名，供后续 VideoFrame 采帧使用。常用预设：`camera`, `cam0`。

## 输出

* 类型: `string`
* 描述: 打开相机设备返回的句柄变量或状态标识。

## 使用示例

```json
{
    "tag":  "CameraOpen",
    "device":  "0",
    "size":  "",
    "output_var":  "camera"
}
```
