# 回放录制 (PlayRecord) (PlayRecord)

以指定速度回放之前录制好的鼠标轨迹与键盘击键动作

## 运行参数

* **宏记录表名 (`name`)**
  * 类型: `string`
  * 默认值: `""`
  * 描述: 在宏录制服务中持久化的事件清单表名。
* **随机抖动偏移(px) (`radius`)**
  * 类型: `number`
  * 默认值: `0`
  * 描述: 模拟真实人工操作的随机偏移像素半径。常用预设：`0`, `5`, `10`, `20`。
* **回放速度倍率 (`speed`)**
  * 类型: `number`
  * 默认值: `1.0`
  * 描述: 时间间隔加速或减速倍率。常用预设：`1.0`, `1.5`, `2.0`, `3.0`, `5.0`。
* **循环次数 (`repeat`)**
  * 类型: `number`
  * 默认值: `1`
  * 描述: 执行该操作序列的重复次数。常用预设：`1`, `2`, `5`, `10`。
* **循环间隙(ms) (`interval`)**
  * 类型: `number`
  * 默认值: `0`
  * 描述: 每次循环之间的暂停等待时长 (毫秒)。常用预设：`0`, `100`, `500`, `1000`。

## 输出

* 类型: `number`
* 描述: 键鼠宏操作序列回放执行结果回执。

## 使用示例

```json
{
    "tag":  "PlayRecord",
    "name":  "",
    "radius":  0,
    "speed":  1,
    "repeat":  1,
    "interval":  0
}
```
